## 2. Correções de Bugs (Seção 2)

1. **Abas cortadas em Bens**:
   - Formato ajustado para `'${aba.rotulo} ${aba.contagem}'` (sem parênteses).
   - Rolagem horizontal habilitada (`SingleChildScrollView(scrollDirection: Axis.horizontal)`) garantindo que nenhum rótulo seja truncado em telas estreitas.
2. **Fonte única de verdade da Unidade Ativa**:
   - `unidadeAtivaIdProvider` agora é atualizado imediatamente no `ImportacaoService` ao importar ou carregar demonstração (`unidadeAtivaIdProvider.notifier.state = dados.unidade.id.value`).
   - `MaisScreen` agora consome consistentemente `unidadeAtivaProvider` e exibe os dados da comarca.
3. **Barra Superior Unificada**:
   - `AppShell` consulta `unidadeAtivaProvider`: exibe o nome da unidade ativa em todas as abas (`Comarca de Breves`), revertendo para `"Tombox"` apenas se nenhuma unidade estiver carregada.
4. **Início com Unidade recém-carregada**:
   - Quando não há salas conferidas (`conferidos == 0`), exibe: `"15 salas e 300 bens. Nenhuma sala conferida ainda."` em vez de mensagens imprecisas.
5. **Relatório de Importação (Linguagem v2)**:
   - Reescrito utilizando `ListaDados` e texto corrido conciso.
   - Botão de ação principal alterado para `"Ver salas"`, sem ícones de seta, alinhado à identidade visual institucional.
6. **Perfil Padrão**:
   - `PerfilUsuario` inicializa vazio por padrão (`configurado == false`). O perfil demonstrativo (`Rosilene Silva`) só é injetado durante o carregamento de dados de demonstração.
